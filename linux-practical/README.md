# linux-practical (workspace mirror)

This folder mirrors the `~/linux-practical` workspace you build inside the Linux VM (Task 4).

```
linux-practical/
├── config/      app.conf
├── documents/   overview.txt, tasks.txt
├── backups/     overview.txt, app.conf
└── evidence/    terminal captures and screenshots
```

After finishing in the VM, copy your real files here (see `docs/MOVING_FILES_FROM_VM.md`) and delete the `.gitkeep` placeholders if you wish (optional).
